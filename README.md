# Yggdrasil Flipping Agents

3-agent system for iPhone flipping workflow (part of RAGNAROK / Yggdrasil AI OS).

## Agents

- **01-triage-agent.md** – Fast filter (IGNORE / MAYBE / PURSUE)
- **02-core-analyst-agent.md** – Extraction, market/repair estimates, scenarios, verdict
- **03-output-agent.md** – Forge Packet + Facebook Marketplace listing (triggered by command)

Current recommended setup for solo workflow. Collapsed from original 6-agent version for practicality.

## Usage

Run agents in sequence:
1. Triage new listings
2. Core Analyst for full analysis
3. Output (Forge / Facebook post) only on explicit trigger
